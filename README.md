Website portofolio yang saya buat ini memiliki 5 bagian.
Pertama, bagian "Home". Di bagian ini menampilkan perkenalan singkat tentang diri saya.
Kedua, bagian "Pendidikan". Bagian ini menampilkan riwayat pendidikan saya dari SD sampai sekarang (kuliah).
Ketiga, bagian "Portofolio". Bagian ini menampilkan projek-projek yang sudah pernah saya buat dengan penjelasan singkat dari masing-masing projek.
Keempat, bagian "Kontak". Bagian ini menampilkan form untuk mengirim pesan. Formnya berisikan nama, email, dan pesan.
Kelima, bagian Footer. Bagian ini menampilkan sosial media saya (X, Instagram, Facebook, dan GitHub).
Lalu saya ada kasih efek hover pada bagian tombol "Home", "Pendidikan", "Portofolio", dan "Kontak". Selain itu juga saya kasih efek hovernya di bagian footer.
Saya ada kasih juga efek hover pada isi bagian "Pendidikan" dan "Portofolio". Jadi kalo cursor user mengarah pada kotak yang berisi bagian riwayat pendidikan dan portofolio, akan ada efek hover yang sudah saya berikan.
